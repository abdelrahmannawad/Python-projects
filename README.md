# Python Projects

A collection of small Python projects covering automation, security basics, and everyday utilities.

## Projects

| Project | Description |
|---|---|
| **file-organizer** | Sorts files in a folder into categories to keep directories tidy. |
| **password-checker** | Checks how strong a password is and gives feedback. |
| **simple-network-scanner** | A basic network scanner for learning how hosts and ports are discovered. |
| **wellness-logger** | Logs daily wellness entries from the command line. |

Each project is packaged as a `.zip` archive in this repository.

## Getting started

1. Download the `.zip` for the project you want.
2. Unzip it and open the folder in a terminal.
3. Run it with Python 3, for example `python main.py` (check the project's files for the exact entry point).

## Notes

These projects were built for learning and practice. The network scanner should only be used on networks you own or have permission to test.
